시스템행거
흔들림·처짐 수리

흔들리는 행거는 원인부터 찾아야 제대로 고쳐집니다.

시스템행거가 흔들리는 흔한 원인은 천장을 누르던 폴의 고정이 느슨해졌거나, 선반 브래킷이 빠져 한쪽으로 무게가 몰린 경우입니다. 옷 무게가 계속 걸리면 선반이 처지고 옷봉이 휘기도 합니다.

코니처는 흔들리는 칸을 확인해 필요한 부분을 해체하고, 폴 고정과 브래킷 위치, 수평을 다시 맞춰 재조립합니다. 휘거나 부러진 부품은 다시 쓸 수 있는지 먼저 판단해 알려드립니다.

Situations

이런 증상이 있으면 점검이 필요합니다

행거 전체가 흔들릴 때

천장과 바닥을 지지하는 폴의 고정이 느슨해졌을 수 있습니다.

선반 한쪽이 내려갈 때

브래킷이 빠졌거나 위치가 어긋났는지 확인합니다.

옷봉이 휘었을 때

한 칸에 무게가 몰렸는지, 브래킷이 버티는지 봅니다.

직접 다시 세웠더니 불안할 때

조립 순서나 수평이 맞지 않았을 수 있습니다.

Process

수리 진행 순서

  1. 증상 사진·영상

    흔들리는 부분을 영상으로 보내주시면 원인을 먼저 짐작합니다.

  2. 원인 확인

    방문해서 고정부와 브래킷 상태를 확인합니다.

  3. 부분 해체

    문제가 있는 칸만 해체하는 것부터 검토합니다.

  4. 재조립·수평 조정

    고정과 수평을 다시 맞춰 조립합니다.

  5. 하중 점검

    옷을 걸었을 때 흔들림이 없는지 확인합니다.

FAQ

자주 묻는 질문

흔들리는 영상을 보내도 되나요?

네, 10초 정도 흔들어 보는 영상이 있으면 어느 부분이 문제인지 더 정확히 볼 수 있습니다.

벽 구멍이 커졌는데 메워 주나요?

벽 보수는 하지 않습니다. 대신 다른 위치에 다시 고정해 흔들림을 잡는 방법을 안내해 드립니다.

부품이 부러졌어요

어떤 부품인지 사진으로 보여주세요. 다시 쓰기 어려운 부품이면 미리 알려드립니다.

전체를 다 해체해야 하나요?

흔들리는 칸만 부분 해체해서 해결되는 경우도 있습니다. 증상을 보고 판단합니다.

옷은 빼 두어야 하나요?

작업할 칸의 옷과 물건은 비워 두셔야 합니다. 나머지 칸은 그대로 두셔도 됩니다.

흔들리는 부분 영상을 보내주세요

흔들리는 모습이 담긴 짧은 영상과 행거 전체 사진이면 원인을 먼저 살펴볼 수 있습니다.
