보관해 둔 시스템행거
다시 설치

오래 보관한 행거일수록 부품 확인부터 시작합니다.

입주 날짜가 늦어져 짐을 맡겼거나, 베란다에 몇 달 두었던 행거를 다시 쓰려고 하면 어떤 부품이 어디 것인지 기억나지 않는 경우가 많습니다. 보관 중에 나사 봉투가 없어지거나 선반 모서리가 눌리기도 합니다.

코니처는 설치 전에 보관된 부품을 펼쳐 칸별로 다시 맞춰 보고, 빠진 부품이나 손상된 부분을 먼저 확인합니다. 그다음 새 공간 치수에 맞춰 배치를 정하고 설치합니다.

Situations

이런 경우 보관 후 설치가 필요합니다

짐을 맡겼다가 입주할 때

보관했던 부품이 새 집에 도착하면 설치를 진행합니다.

베란다·창고에 두었을 때

습기로 상한 부품이 없는지 먼저 확인합니다.

해체한 사람이 다를 때

다른 곳에서 해체한 행거도 부품을 맞춰 설치합니다.

설명서가 없을 때

부품 모양과 연결 방식으로 구조를 파악해 조립합니다.

Process

보관 부품 설치 순서

  1. 부품 사진

    보관한 부품을 한곳에 펼쳐 찍어 보내주세요.

  2. 부품 맞춰 보기

    칸별로 필요한 부품이 모두 있는지 확인합니다.

  3. 배치 정하기

    새 공간 치수에 맞춰 설치할 구성을 정합니다.

  4. 설치

    칸별로 세우고 부속을 제자리에 결합합니다.

  5. 점검

    보관 중 생긴 틀어짐이 없는지 수평을 확인합니다.

FAQ

자주 묻는 질문

나사 봉투를 잃어버렸어요

어떤 종류의 연결 부품이 필요했는지 부품 사진으로 확인해 안내드립니다.

습기에 선반이 조금 부풀었어요

상태를 사진으로 보고 다시 쓸 수 있는지 판단합니다. 눈에 덜 띄는 칸에 배치하는 방법도 있습니다.

몇 년 보관한 것도 되나요?

보관 기간보다 부품 상태가 중요합니다. 사진으로 먼저 확인해 드립니다.

원래와 다른 방에 설치해도 되나요?

네, 새 방 치수에 맞춰 배치를 다시 정합니다.

부품이 아직 새 집에 없어요

부품이 도착한 뒤에 방문해 설치합니다. 도착 예정일을 알려주시면 일정을 맞춥니다.

보관한 부품을 한 번에 펼쳐 찍어 주세요

폴·선반·연결 부품이 보이게 찍은 사진과 설치할 공간 치수를 문자로 보내주세요.
